# Naruka Wealth - All-India Alpha Strategy Dashboard
AMFI Registered Mutual Fund Distributor (ARN 277301)
Website: https://rahul-naruka.github.io/stock/

## Overview
This zip archive contains the complete, self-contained interactive web dashboard for your all-India stock alpha strategy.

### Features Included:
1. **Post-Market Daily Data Sync**: Auto-updates closing prices, daily percentage changes, and portfolio valuations after market close.
2. **21-Year Backtest Simulation (2005–2026)**: Visualizes historical growth starting from ₹1,00,000 against Nifty 500 TRI benchmark.
3. **Interactive Capital Allocation**: Input any corpus amount to instantly compute exact rupee weights across all 12 recommended stocks.
4. **Governance & Risk Controls**: Integrated zero promoter pledging filters and high operating cash flow conversion thresholds.

### Deployment Instructions:
Extract `index.html` into your GitHub repository connected to `rahul-naruka.github.io/stock/` and push to `main`.
